PetGrow 관리자/고객지원 통합 업데이트
- 최고관리자/운영관리자/신고관리자/광고관리자 역할별 화면 + 서버 권한 분리
- 최고관리자 전용 관리자 목록/닉네임 검색/추가/권한변경/삭제/PIN 초기화
- 추가 관리자는 첫 관리자센터 접속 시 자기 6자리 PIN 최초 설정
- 최고관리자 삭제·강등 방지
- 관리자센터 열기 버튼 모바일 중앙 정렬
- 신고 제재/해제/검토완료 확인 절차 유지
- 공지사항 + 문의/피드백 고객지원 페이지
- 문의 기본 비공개, 공개 선택 가능
- 비공개 문의는 작성자와 권한 있는 운영진만 조회
- 공개 문의는 회원이 본문과 운영진 답변 열람 가능
- 공지/문의 페이지당 20개
- 관리자센터 문의관리/공지관리 추가
- 문의 답변 상태(답변대기/확인중/답변완료) 지원
- 관리자용 고객지원 API도 관리자 PIN 토큰 + 역할을 서버에서 재검증
- 이용약관/개인정보처리방침에 문의·피드백 기능 반영
- 전체 API JS 문법 검사 완료
