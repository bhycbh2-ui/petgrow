PetGrow Pet음악 + UI 최종 반영 (2026-08-16)

1. Pet음악 신규 메뉴
- 기존 PetGrow 민트/화이트/둥근 카드 디자인 유지
- 전체 / 강아지 / 고양이 탭
- 인기 TOP5 상단 고정
- 커버 이미지 중심 카드
- 제목 / 업로드일 / 재생수 / 좋아요 / 댓글 표시
- 1곡 반복 / 전체 반복 / 반복 OFF
- 음원 다운로드 기능 없음
- 목록 20곡 단위 페이지 구분

2. 관리자센터 연동
- Pet음악 관리 탭 추가
- 음원 파일 + 제목 + 커버 이미지 + 강아지/고양이/공용 분류 등록
- 설명 선택 입력
- 업로드일 자동 기록
- 공개/비공개, 수정, 삭제
- 재생수/좋아요/댓글 수 확인
- 사용자 Pet음악 화면과 동일 DB 연동

3. 노출 위치
- 홈 서비스 카드
- 소개 페이지 핵심 기능 및 별도 Pet음악 안내
- 이용가이드 / 정보가이드
- PC 사이드바 / 모바일 메뉴
- 관리자 메뉴 이용 통계에 Pet음악 추가

4. 이용약관 / 개인정보처리방침
- Pet음악 재생/반복/좋아요/댓글/인기순위 기능 반영
- 음원 다운로드 미제공 및 무단 추출·재배포 금지 안내
- Pet음악 좋아요/댓글 참여 기록 처리 내용 반영
- Vercel Blob의 Pet음악 음원/커버 저장 용도 반영

5. 고객지원/영문 UI
- 고객지원 '돌아가기' 버튼을 헤더 오른쪽으로 이동
- 문의 공개 체크 안내: '체크 해제하면 운영진만 볼 수 있어요.'
- 영문 footer '광고·제휴 문의' → 'Partnerships'

검증
- TypeScript JSX parser(tsc)로 App.jsx 문법 검사 통과
- node --check로 api/music.js 및 api/_lib/db.js 문법 검사 통과
- npm 의존성 설치가 환경 제한으로 시간 초과되어 Vite 최종 build는 이 환경에서 실행하지 못함
