관리자 계정/닉네임 입력 수정

관리자
- 현재 로그인 계정이 관리자 아닌데 기존 관리자 행이 남아있는 경우 '관리자 등록/복구' 제공
- ADMIN_SETUP_CODE + 새 6자리 PIN을 모두 정확히 입력해야 복구 가능
- 복구 시 현재 로그인 카카오 계정을 관리자에 연결하고 기존 관리자 지정 해제
- 관리자센터는 복구/등록 완료된 관리자 계정에만 실제 접근 가능
- 복구 처리 ADMIN_RECOVERY 로그 기록
- 복구 후 ADMIN_SETUP_CODE 변경 권장

닉네임
- 변경하기 클릭 시 입력창 즉시 활성화
- 커서 자동 포커스 및 기존 닉네임 자동 선택
- 입력창이 disabled처럼 완전히 막혀 보이지 않도록 readOnly 방식으로 개선
- 2~8자/중복/금칙어 서버 검사는 기존대로 유지

기존 기능
- 신고관리, 1/7/30일/영구 제한 및 해제
- 관리자 통계/운영로그
- 로딩/렌더 수정 및 KO/EN 정렬 수정 유지
