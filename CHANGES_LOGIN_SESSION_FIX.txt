로그인 후 다시 로그인으로 보이는 버그 수정

원인
- /api/me가 로그인 상태 확인만 하는데 전체 Pet톡/통계 DB 스키마 초기화를 기다림
- cold start에서 6초를 넘기면 fetchMe가 null을 반환해 실제 세션이 살아 있어도 UI가 로그아웃으로 표시됨

수정
- 회원/관리자 인증 전용 ensureAuthSchema 분리
- /api/me와 카카오 로그인 사용자 생성은 가벼운 인증 스키마만 사용
- 관리자 여부 확인도 전체 통계 스키마를 기다리지 않음
- /api/me는 401만 실제 로그아웃으로 판정
- 일시적 5xx/timeout은 1회 재시도
- 창/앱이 다시 활성화되면 세션을 자동 재확인
- 기존 관리자/통계/PetBTI/신고 기능 유지
