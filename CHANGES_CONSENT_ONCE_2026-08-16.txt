PetGrow 카카오 로그인 동의 최초 1회 처리
- 현재 동의 버전(2026-08-16-v1)의 필수 동의 기록이 localStorage에 있으면 로그인 화면에서 동의 체크 UI를 다시 표시하지 않음
- 이미 동의한 사용자는 카카오 로그인 버튼을 바로 사용할 수 있음
- 최초 사용자만 이용약관/개인정보 수집·이용 필수 동의를 진행
- 선택 광고·마케팅 동의 여부도 기존 기록에서 복원
- 향후 중요한 약관 변경 시 CONSENT_VERSION을 v2 등으로 올리면 자동으로 재동의 화면 표시
- 로그인 성공 후 기존과 같이 동의 기록을 계정 상태에 동기화
