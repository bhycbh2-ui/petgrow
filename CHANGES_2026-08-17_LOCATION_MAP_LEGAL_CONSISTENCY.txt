PetGrow 내 주변 Pet 위치/지도/문구 정리
- 내 주변 Pet 진입 시 선택적 위치 권한 요청 유지
- 위치 권한 거부 시에도 주소 검색 정상 이용
- 지도 헤더에 내 위치 표시/위치 다시 확인 버튼 추가
- VITE_KAKAO_JAVASCRIPT_KEY가 있으면 Kakao Maps Web SDK 우선 사용, 없으면 기존 Leaflet/OSM 지도 폴백
- 검색 기준은 입력한 주소, 현재 위치는 지도 표시와 업체까지 거리 계산에만 사용
- 위치 허용 시 업체 목록을 내 위치 거리 기준으로 정렬
- 업체 목록 10개씩 페이지 구분
- 거리 표시 영역 폭/정렬 통일
- 도움말, 소개, 개인정보처리방침, 이용약관, 로그인 개인정보 동의창의 위치 관련 문구를 동일 기준으로 정리
- 개인정보처리방침 및 이용약관 최종 업데이트/시행일 2026-08-17 반영
