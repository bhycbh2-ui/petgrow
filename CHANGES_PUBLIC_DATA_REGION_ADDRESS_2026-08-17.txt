PetGrow 내 주변 Pet 공공데이터 지역/주소 보완
- 현재 위치의 시·군·구를 기준으로 공공데이터 후보 조회
- 도로명주소(ROAD_NM_ADDR) + 지번주소(LOTNO_ADDR) 각각 조회 후 병합
- 각 주소 조건 최대 1000건 × 5페이지까지 조회
- 실제 좌표를 WGS84로 변환 후 현재 위치 거리 계산
- 1km 이내 공식 등록업체 우선 노출
- 공공데이터 주소에 *** 등 마스킹이 있으면 카카오 장소정보로 정상 주소 보완
- 전화번호/카카오맵 링크도 카카오로 보완
- 상호명 검색 실패 시 업종 키워드 + 공공데이터 좌표 주변 700m 재검색
- 카카오에서도 주소 확인 불가 시 시·군·구·동 수준까지만 표시
- 전화번호가 없으면 전화번호 줄 숨김
- Vercel Hobby API 함수 추가 없음
