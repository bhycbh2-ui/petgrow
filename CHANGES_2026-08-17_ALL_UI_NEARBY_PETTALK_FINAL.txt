PetGrow 통합 UI/내 주변 Pet/Pet톡 수정
- 내 주변 Pet: '전체'는 병원/약국/펫샵/미용/호텔·유치원 개별 API를 병렬 조회 후 병합
- 개별 카테고리 결과를 메모리 캐시해 카테고리 전환 시 즉시 표시
- 내 위치 찾기 별도 버튼 제거: 지역명 빈 상태에서 '검색' 누르면 위치 권한 요청
- 위치 검색 안내 문구 추가
- 모바일 내 주변 Pet 카테고리: 핵심 3개 + 더보기 방식으로 한 줄 유지
- Pet톡: 검색 버튼 + 글쓰기 버튼 명확히 분리, 검색은 Enter/검색 버튼 실행
- 회원정보: Pet톡 내 활동 버튼 바로 아래에 활동 내용 펼침, 그 다음 좋아요한 Pet음악 배치
- 광고·제휴 문의 돌아가기: 홈으로 이동
- Pet정보: 질문 펼침 답변 영역 흰색 카드로 분리해 가독성 개선
- 관리자 PIN 화면/푸터 중앙 균형 CSS 보강
