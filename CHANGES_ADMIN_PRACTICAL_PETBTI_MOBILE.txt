관리자 센터 실용화 + 모바일/앱 + PetBTI 통일

관리자 안정성
- 기존 DB에도 pg_users.created_at / last_login_at 컬럼 자동 보강
- 통계 각 항목 독립 조회(Promise.allSettled)
- 일부 통계 오류가 발생해도 관리자 센터 전체가 닫히지 않음
- 오류 팝업 남발 대신 관리자 화면 상단에 '일부 데이터 확인 필요' 안내

실용 대시보드
- 미처리 신고
- 가장 오래된 신고 대기시간
- 현재 이용제한 계정
- 오늘 신규 / 7일 활성 회원
- 오늘 방문 / 현재 접속 추정 / 오늘 페이지뷰
- 오늘 Pet톡 글 / 댓글
- 최근 7일 신고 처리
- 등록 반려동물
- 최근 7일 이용 추이 / 인기 메뉴 / 접속 플랫폼 / 광고 요청 상태

운영로그
- 개발용 action 코드를 한글 운영 문구로 표시
- 최근 24시간 처리 / 7일 이용제한 / 제한해제 / 신고처리 요약
- 가능하면 대상 닉네임 표시(개인정보성 ID 원문 노출 최소화)

모바일/PWA/Android
- 관리자 카드 2열, 상세 패널 1열
- 탭 터치 최적화 및 sticky
- 신고 버튼 2열
- 운영로그 모바일 가독성 개선

PetBTI
- Pet사주와 같은 미등록 아이 화면
- 아이콘 → '등록된 아이가 아직 없어요' → 설명 → '우리 아이 등록하러 가기'
