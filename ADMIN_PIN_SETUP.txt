PetGrow 관리자 PIN 설정

1) Vercel > Settings > Environment Variables에 PETGROW_ADMIN_SETUP_CODE 추가
2) SESSION_SECRET도 반드시 설정되어 있어야 합니다.
3) 배포 후 본인 카카오 계정으로 로그인
4) https://www.petgrow.co.kr/?view=admin 접속
5) 최초 등록 코드 + 숫자 6자리 관리자 PIN 입력
6) 등록 후 재로그인하면 회원정보에 관리자 메뉴 표시

보안 적용: PIN scrypt 해시 저장 / 5회 오류 시 15분 잠금 / 인증 10분 / 서버에서 관리자 권한 재검증 / 관리자 본인 차단 방지 / 처리 로그 저장
