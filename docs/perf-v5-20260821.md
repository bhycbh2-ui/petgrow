# PetGrow 5차 성능 최적화 — 2026-08-21

## 목표

4차에서 Pet톡 피드 자체를 지연 로딩한 뒤에도 메인 App 청크에 남아 있던 Pet톡 하위 화면을 실제 사용 시점으로 이동한다.

## 적용

- `PostComposer` → Pet톡 글쓰기/수정 진입 시 동적 로드
- `PostDetail` → 게시글 상세 진입 시 동적 로드
- `MyActivityPage` → 내 활동 진입 시 동적 로드
- 각 청크는 최초 1회 로드 후 재사용
- 청크 로드 실패 시 사용자용 다시 시도 UI 유지
- 관리자/CMS 등 첫 화면에 필요 없는 보조 런타임 자동 로드 시점을 2.2~4.2초에서 8~12초 이후로 이동
- Service Worker v59
