점검 중 브라우저 확장 자체의 메시지 전달 오류가 있었으며 앱 오류로 집계하지 않았다. 마지막 24시간 운영 로그 조회는 200/401 응답을 반환했으나 로그 보존 범위가 제한적이므로 장애가 전혀 없었다는 근거로 삼지 않는다. 폐기된 일반 로그인 시험 배포의 메일 설정 오류도 현재 카카오 운영 로그인 장애와 구분했다.

첫 카카오 콜백은 서버 로그에서 `state mismatch`로 거부되었고, 새 로그인 요청은 성공했다. 최초 실패의 원인은 확정하지 않았다. 로그인 요청 쿠키·서버 상태의 유효기간은 10분이며, 장시간 인증과 여러 탭에서의 동시 로그인에 대한 추가 재현이 필요하다. PIN 입력 전 화면에 서버 운영 상태의 `상태 조회 실패`가 표시되는 것도 관찰했다. 수정본은 PIN 인증 전에 해당 위젯을 표시하거나 조회하지 않도록 한다.

## 수정 내용

1. 관리자 운영 상태·백업·정합성 API와 남아 있는 포인트 통계 API에 PIN 토큰과 기능별 권한 검사를 적용. 클라이언트에서도 동일 토큰 전송.
2. 데이터 조회 실패를 숨기지 않고 재시도 안내 표시. 서비스 상태가 없는 경우 정상으로 표시하지 않음. 서버의 부분 통계 조회 실패 경고 표시.
3. 신고 합계에 빠진 장소 후기 신고 포함.
4. 일일·주간·월간 보고서와 오늘의 게시글/기능 사용 집계에서 한국 자정 경계를 명시. 날짜 반환 형식도 문자열로 고정.
5. Pet정보 예약 게시 시각을 편집기에 넣을 때 현지 시각으로 변환하여 수정 저장 시 9시간 이동 방지. 한국·UTC·뉴욕 시간대 왕복 검사.
6. 관리자 추가 요청이 기존 최고관리자를 덮어쓰지 않도록 중복은 409로 처리.
7. 신고/광고 관리자 첫 진입을 자신의 권한에 맞는 탭으로 이동. Pet정보 관리 버튼은 실제 허용 역할에만 표시.
8. 관리자 운영 위젯의 계정/PIN 변경·이탈 시 캐시 초기화. 만료된 PIN으로 반복 조회하는 루프 방지.
9. 사진 변경/삭제 시 DB 수정 성공 후 파일 정리. 프로필·다른 기록·게시물·음악·기존 사용자 상태에서 참조 중인 파일을 보존하고, 참조 조회 실패 시 삭제 보류.
10. 일부 스토리지만 검사했을 때 미조회 파일을 누락 파일로 확정하지 않음.
11. 이전 PetPoint 제거 요청 후 남은 서버 차감 중지. 운세·타로가 숨겨진 잔액 때문에 막히지 않도록 처리하고 타로 결과의 차감 문구 제거. 기존 포인트 장부는 보존.
12. 닫힌 모바일 메뉴가 키보드/보조기술에 활성 대화상자로 노출되지 않도록 처리.

음악 재생 집계는 원래 누적값이며 내보내기 문구도 누적으로 표시되어 있다. 기간 재생 이력이 없어 일별 재생 수를 소급 계산할 수 없으므로 이번 수정에서 기간 통계로 바꾸지 않았다.
