# PetGrow 4차 성능 최적화 — 2026-08-21

## 목표

홈 첫 진입에 필요하지 않은 대형 화면을 메뉴 진입 시점에만 내려받도록 분리한다.

## 분리 대상

- 내 주변 Pet
- Pet톡 피드
- 관리자센터
- 관리자센터 > Pet음악 관리 (관리자센터 내부 2단계 lazy load)

Pet뉴스와 PetMusic은 3차 최적화에서 이미 별도 청크로 분리되어 있으며 그대로 유지한다.

## 안정성 처리

- 각 메뉴 청크는 최초 진입 때만 import한다.
- 한 번 로드한 컴포넌트는 메모리에 재사용한다.
- 청크 로드 실패 시 다시 시도 버튼을 제공한다.
- 내 주변 Pet 내부 Leaflet 동적 import 구조는 유지한다.
- 관리자센터 진입만으로 관리자 Pet음악 업로드 코드는 받지 않으며, Pet음악 탭 진입 시 추가 로드한다.
- Service Worker URL을 v58로 갱신해 이전 캐시와 신규 청크가 섞이지 않도록 한다.

## 참고

Vite의 가상 모듈을 사용해 기존 거대 App.jsx의 화면 구현을 빌드 시 안전하게 추출한다. 가상 JSX는 Vite import analysis 이전에 esbuild로 변환하여 빌드 순서에 따른 파싱 오류를 방지한다.
