# PetInfo CMS Operations

Daily PetInfo changes should be performed through the administrator CMS once Phase 2 cutover is complete. Code edits and redeploys should not be needed for routine PetInfo create/edit/hide/delete operations.

Before Phase 2, the database CMS can be populated and verified without changing the live PetInfo reader. Keep the branch isolated until automated checks pass and the existing content set has been migrated and counted.
