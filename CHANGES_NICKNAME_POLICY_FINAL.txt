PetGrow 닉네임 정책 개선

- 닉네임 최대 길이 20자 -> 8자로 변경 (2~8자)
- 닉네임 '변경하기' / '저장하기' 버튼 분리
- 변경하기 클릭 시 입력 가능 상태 + 안내 팝업
- 저장하기 클릭 시 로컬 금칙어/길이/개인정보/운영자 사칭 검사
- 중복 닉네임 체크 API 호출 추가
- 중복일 경우: '이미 사용 중인 닉네임이에요. 다른 닉네임을 사용해 주세요.'
- 금칙어일 경우: '사용할 수 없는 표현이 포함된 닉네임이에요. 다른 닉네임을 사용해 주세요.'
- 저장 성공 시 완료 팝업
- 저장 실패 시 오류 팝업
- 서버에서도 재사용할 수 있도록 api/_nicknamePolicy.js 추가
- 기존 Pet톡/댓글 표시 로직은 변경하지 않음

주의:
프로젝트의 실제 DB 중복 보장을 위해 닉네임 컬럼에는 UNIQUE 인덱스/제약조건이 필요합니다.
프런트/검사 API만으로는 동시에 저장되는 중복을 100% 막을 수 없습니다.
