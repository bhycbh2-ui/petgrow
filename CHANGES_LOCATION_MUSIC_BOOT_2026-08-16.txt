PetGrow 위치·Pet음악 예시·초기 로딩 개선

- 내 주변 Pet 진입 시 현재 위치 권한을 자동 요청
- 위치 허용 시 현재 위치 + 주변 업체 마커를 지도에 표시
- 지도 화면에서 VITE_KAKAO_JS_KEY 의존 제거
- 주변 업체 검색은 기존 서버 KAKAO_REST_API_KEY 사용
- 위치 거부/오류 시 지역명 직접 검색 유지
- Pet음악 예시곡: 핑크빛 하루 추가 (public/petmusic/pink-day.mp3)
- Pet음악 데이터가 처음 비어 있을 때 예시곡을 DB에 1회 등록하여 관리자센터에서도 수정/비공개/삭제 가능
- 예시 커버는 PetGrow 기본 로고 사용(관리자센터에서 교체 가능)
- 초기 로딩 중 빈 화면 대신 홈 스켈레톤 UI 표시
- 스플래시가 오래 남지 않도록 React 스켈레톤 준비 후 자연스럽게 전환
