PetGrow 전체 모바일 화면 배율 개선

- index.html viewport를 width=device-width, initial-scale=1, viewport-fit=cover 로 통일
- iOS Safari 자동 글자 확대 방지: text-size-adjust 100%
- iPhone에서 16px 미만 입력칸 터치 시 발생하는 자동 화면 확대 방지
  → 모바일 input / textarea / select를 최소 16px로 적용
- #root/body 및 주요 페이지가 100vw를 초과하지 않도록 폭 제한
- 관리자센터, 서비스상태, 광고운영, 공지/문의 등 긴 페이지의 가로 overflow 방지
- 이미지/비디오/SVG가 모바일 viewport보다 커지지 않도록 보정
- 모든 모바일/웹앱/Capacitor 앱 공통 스타일로 적용
- 접근성을 위해 user-scalable=no / maximum-scale=1 같은 강제 확대 금지는 사용하지 않음
- API JS 문법 및 핵심 함수 중복 검사 통과
